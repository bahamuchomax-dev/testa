# Oriex Next v0.3.0

学習記録・単語帳・復習クイズ・英Run語をひとつにした、ローカルファーストの学習PWA（全面刷新プロトタイプ）。

- データはすべて端末内（localStorage）に保存。マイページから書き出し / 読み込み / 初期化が可能
- 旧Oriexと同じURL配下に置いた場合、参考書ログとランのベスト記録を初回起動時に自動引き継ぎ
- ログイン・フレンド・先生用機能・お知らせ等のオンライン機能は本バージョンには含まれません（次段階）

## 公開方法
このフォルダの中身をそのまま静的ホスティング（GitHub Pages等）へ。
旧アプリ(v5.2.x)と同じリポジトリ直下に置くと旧アプリを置き換えます。併存させる場合は別フォルダ（例: /next/）または別リポジトリを推奨。
